# Group Anagrams (字母异位词分组)

## 📌 主题标签 (Topics)
- `Hash Table` (哈希表)
- `String` (字符串)
- `Sorting` (排序)
- `Array` (数组)

## 💡 解法与原理 (Solutions & Principles)

### 方法一：排序哈希法 (Sorting + Hash Map)
* **核心原理**  
  互为字母异位词（Anagrams）的字符串，虽然内部字符顺序不同，但包含的字符种类和数量完全一致。因此，将字符串中的字符按字母序**升序排序**后，同一组的异位词都会变成**完全相同的规范字符串**（Canonical Key）。
* **解法逻辑**  
  1. 构造映射关系：建立“排序后的特征键”到“原始字符串列表”的哈希映射（Key: 排序字符串，Value: 同组原始字符串数组）。
  2. 遍历归类：对每个输入的字符串生成排序副本作为 Key，并将原始字符串存入对应的桶中。
  3. 收集结果：遍历哈希表，提取所有桶内的字符串数组并组装成二维结果集。

### 方法二：字符计数哈希法 (Frequency Count + Hash Map)
* **核心原理**  
  在字符集受限（如仅包含 26 个小写英文字母）的场景下，互为异位词的字符串拥有完全相同的**字符频次统计图谱**。通过将 26 个字母的出现次数序列化为一个唯一的键（例如用分隔符连接每个字母的计数），无需进行字符串排序即可生成统一的 Key。
* **解法逻辑**  
  1. 频次统计：遍历字符串，使用长度为 26 的数组记录各个字母出现的频次。
  2. Key 序列化：将频次数组拼接/编码为一个固定的特征字符串（如 `a1b0c2...`）。
  3. 归类与汇总：利用该特征字符串在哈希表中进行分组，最后收集所有分组列表。

## ⏱️ 复杂度分析 (Complexity)
| 解法 | 时间复杂度 | 空间复杂度 | 适用场景与评估 |
| :--- | :--- | :--- | :--- |
| **排序哈希法** | $O(N \cdot L \log L)$ | $O(N \cdot L)$ | **优点**：结构清晰、代码简练。<br>**适用**：字符串平均长度 $L$ 较短的绝大多数场景。 |
| **字符计数哈希法** | $O(N \cdot L)$ | $O(N \cdot L)$ | **优点**：时间复杂度达到理论最优，避免了排序开销。<br>**适用**：字符串长度 $L$ 很大且字符集较小的场景。 |

> **参数说明**：
> - $N$ 为字符串数组中的元素数量（`strs` 的长度）。
> - $L$ 为字符串的平均/最大长度。
