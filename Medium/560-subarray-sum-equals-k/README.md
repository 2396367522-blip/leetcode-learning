# Subarray Sum Equals K

## 思路
暴力方法可以枚举所有连续子数组并计算其和，时间复杂度为 **O(n²)**。
观察区间和可以发现：
> 区间和 = 前缀和之差
设 `prefix[i]` 表示前 `i` 个元素的前缀和，则任意区间 `[l, r]` 的和为：
```text
prefix[r] - prefix[l - 1]
```
如果某个区间的和等于 `k`，则有：
```text
prefix[r] - prefix[l - 1] = k
```
移项得到：
```text
prefix[l - 1] = prefix[r] - k
```
因此，在遍历数组计算当前前缀和 `current_sum` 时，只需要快速判断 **之前是否出现过前缀和 `current_sum - k`**。为了实现 O(1) 查询，可以使用哈希表记录每个前缀和出现的次数。
遍历过程：
1. 更新当前前缀和 `current_sum`。
2. 查找 `current_sum - k` 是否出现过，若出现，则将其出现次数加入答案。
3. 将当前前缀和加入哈希表，供后续位置使用。
需要注意初始化：
```cpp
prefix_count[0] = 1;
```
表示空前缀出现一次，使得从数组第一个元素开始的合法区间也能被正确统计。

## 知识点
- Prefix Sum（前缀和）
- Hash Table（哈希表）
- 前缀和 + 哈希表
- 数学转换（区间和 → 前缀和差）

## 复杂度
- **时间复杂度：** `O(n)`
- **空间复杂度：** `O(n)`
